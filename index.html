PHYSICAL MODEL ASSUMPTIONS & SCIENTIFIC LIMITATIONS
  • Bathymetric Geometry: Riverbed bathymetry is reconstructed from OPW survey cross-sections; dynamic scour and localized sediment transport during peak velocity are not simulated.
  • Catchment Runoff: Uses Clark Unit Hydrograph (Tp = 7.5h, K = 18.0h, C = 0.42) driven by ECMWF NWP point forecasts scaled over the 2,173 km² Suir basin.
  • Hydrodynamic Model: 2D well-balanced Kurganov-Petrova SWE with Audusse hydrostatic reconstruction; Manning roughness n = 0.035 (channel) and n = 0.050 (floodplain).
  • Data Degradation Protocol: In the event of upstream telemetry failure or network latency, system transitions to CACHED_PROVISIONAL mode with clear provenance stamping rather than fabricating unobserved data.
